# Soko Tattoo / Formula 19

A booking-first website for Soko Tattoo / Formula 19 in Nairobi West. The site presents custom tattoo and piercing services alongside professional tattoo kit, ink, jewelry, and wholesale supply enquiries.

## Live site

The production site is deployed on Vercel at `https://soko-tattoo-formula19.vercel.app`.

## Local development

```bash
pnpm install
pnpm dev
```

The checked-in source lives in `client/src`; the deployable static build is generated into `dist/public` with `pnpm build`.
